# SUWEY Stok

Satışçılar için SUWEY ürün stok uygulaması: https://suweytriko.github.io/suwey-stok/

- `data.json`: güncel stok (STOK RAPORU sayfasından) ve fotoğraf listesi
- `photos/`: ürün ve renk fotoğrafları
- Telefonda ana ekrana eklenebilir (iPhone: Safari → Paylaş → Ana Ekrana Ekle; Android: Chrome → ⋮ → Ana ekrana ekle)
